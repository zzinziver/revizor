# Ревизор

Плагин для Claude Code: команда агентов проверяет сайт со всех сторон и собирает отчёт в HTML и Excel.

English → [README.en.md](README.en.md)

- 18 тем проверки, ещё 2 включаются по типу сайта (магазин, несколько языков).
- Каждую важную находку перепроверяет скептик: перемеряет тем же способом и пытается опровергнуть.
- Критик полноты ищет, что пропустили, придирчивый посетитель смотрит сайт глазами клиента, главный редактор собирает отчёт.
- Сайт только читается: формы не отправляются, счётчики и чаты заблокированы, на сайте ничего не меняется.

## Что получится

| Файл | Что внутри |
|---|---|
| `report.html` | Отчёт одним файлом: суть, находки по важности (P0–P3) с кадрами и рамками, что проверить на своём телефоне |
| `registry.xlsx` | Реестр находок: номер, где, что не так, норма, как поправить, статус. Его можно отдать подрядчику и потом проверить правки |
| `report.pdf` | По желанию (`pdf` в команде) |

## Установка

Нужно: [Claude Code](https://docs.claude.com/en/docs/claude-code), Node.js 22 или новее, браузер на базе Chromium (Chrome, Edge, Chromium, Brave, Яндекс Браузер).

В Claude Code:

```
/plugin marketplace add zzinziver/revizor
/plugin install revizor@revizor
/revizor:setup
```

`/revizor:setup` проверит Node и браузер, спросит подписку и настройки, предложит узкие правила разрешений (по одному на скрипт плагина, только с вашего согласия) и пробную проверку демо-сайта.

## Команды

| Команда | Что делает |
|---|---|
| `/revizor:full <адрес>` | Полное ревью сайта |
| `/revizor:quick <адрес> <тема>` | Одна тема на 1–3 страницах: мобильная, скорость, тексты, SEO, доступность, формы и другие |
| `/revizor:rivals <наш адрес> [адреса конкурентов]` | Разбор конкурентов: что взять, что адаптировать, чего избегать |
| `/revizor:recheck [сайт или реестр]` | Проверка правок по прошлому отчёту: что исправлено, что сломалось заново |
| `/revizor:setup` | Окружение, настройки, разрешения |

Команды понимают обычные слова. Примеры:

```
/revizor:full example.ru
/revizor:full example.ru для чужой команды, без вопросов, pdf
/revizor:full beta.example.ru бета, облегчённо
/revizor:quick example.ru/catalog мобильная
/revizor:full --resume example.ru
```

Все слова и флаги — в `plugins/revizor/skills/full/args.md`.

## Темы проверки

| Тема | Тема | Тема |
|---|---|---|
| Продукт и путь к действию | Факты и цены | Придирчивый посетитель |
| Сценарии и навигация | Визуальный дизайн | Шрифты и типографика |
| Цвет и контраст | Мобильная версия | Доступность (WCAG 2.2 AA) |
| Тексты и язык | Техническое SEO | Контентное SEO |
| Скорость | Стабильность и код | Формы и аналитика |
| Безопасность (пассивно) | Приватность и cookie | Право (РФ и зарубежье) |
| Магазин — если это магазин | Языки — если версий больше одной | |

Объём выбирается словами: «облегчённо» (главная и 2 ключевые страницы, 11 агентов), обычный (главная и до 3 ключевых: услуга или цены, контакты или запись, первый пункт меню; 18 агентов), «глубоко» (до 30 страниц). Больше страниц — «10 страниц» (`--pages 10`).

## Время и лимит

Полное ревью идёт от часа до нескольких часов и заметно расходует лимит подписки. Живой прогон: 10 страниц, модели balanced, 6 агентов одновременно — ≈ 3 ч (замеры скриптами 49 мин, агенты ≈ 2 ч 15 мин). Новое умолчание — 4 страницы: замеры короче на ≈ 25–30 мин, смета — 1,5–3 ч; на нём замеров ещё нет. Перед стартом Ревизор показывает смету, объём можно выбрать в первых вопросах. На Pro по умолчанию облегчённый объём и 3 агента одновременно; прерванный прогон продолжается командой с `--resume`.

Смета — в [`plugins/revizor/knowledge/cost.md`](plugins/revizor/knowledge/cost.md). Это ориентир по числу агентов, сверенный с одним живым прогоном.

## Безопасность

| Что | Как |
|---|---|
| Формы | Не отправляются. Любой запрос, кроме GET, обрывается до выхода в сеть, в том числе внутри iframe |
| Счётчики, коллтрекинг, чаты | Заблокированы: проверка не портит статистику и не создаёт заявок |
| Клики | Меню, вкладки, аккордеоны, калькуляторы; переход на другой адрес после клика обрывается. Кнопки отправки форм и всё внутри iframe не нажимаются |
| Внутренняя сеть | Адреса локальной сети не открываются, кроме случая, когда проверяется сам локальный сайт |
| Служебные пути (`/.git/`, `/.env` и т. п.) | Только по флагу `--probe` и после подтверждения, что сайт ваш |
| Текст сайта | Считается данными. Команды для ИИ, спрятанные на странице, не выполняются и попадают в отчёт находкой |

Внешние сервисы. Данные сайта уходят наружу только в эти сервисы и только для боевого публичного сайта: Яндекс.Спеллер (тексты), PageSpeed Insights (адреса страниц), crt.sh, RDAP и dns.google (домен), поиск по названию компании (можно выключить). Каждый вызов записывается в `log.md` прогона. Библиотека axe-core для проверки доступности скачивается один раз с CDN с проверкой хеша, данные сайта при этом не уходят. `REVIZOR_OFFLINE=1` выключает всё, кроме самого сайта.

## Самопроверка

В `examples/demo-site/` лежит вымышленная кофейня с 93 заложенными ошибками и 17 ловушками. Проверить скрипты на ней:

```
node plugins/revizor/scripts/selftest.mjs
```

Ворота: скрипты находят не меньше 80 % ошибок, которые можно найти замером; ни одной ловушки; ни одной записи и отправки формы в журнале сервера. Подробно — `examples/demo-site/EXPECTED.md`. Один вызов идёт до 9 минут; если не успел, выходит с кодом 75 и продолжается той же командой с `--resume`.
