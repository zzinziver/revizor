# Ревизор в Проекте claude.ai

Облегчённая версия Ревизора для тех, у кого нет Claude Code. Те же чек-листы и правила, но без скриптов: страницы читает Claude, скриншоты присылаете вы (или снимает Claude в Chrome, если он подключён).

## Как подключить

1. На claude.ai: **Projects → Create project**, название — «Ревизор».
2. **Project instructions** → вставьте целиком текст `project-instructions.md` (5,5 тыс. знаков).
3. **Project knowledge** → загрузите 7 файлов из `knowledge/`.
4. Если тариф даёт место — ещё файлы из `knowledge-extra/`: они нужны для платформ сайтов, типов сайтов, языка и разбора конкурентов.

| Папка | Файлы | Объём | Что внутри |
|---|---|---|---|
| `knowledge/` | `01-core.md` … `07-market-index.md` (7) | ≈ 397 тыс. знаков, ≈ 115–140 тыс. токенов | поведение и безопасность, важность и формат находки, тон и отчёт, чек-листы всех тем, скептик, рынок РФ |
| `knowledge-extra/` | `08-platforms.md` … `12-reference.md` (5) | ≈ 314 тыс. знаков | платформы (Тильда, WordPress, Битрикс…), типы сайтов, нейрослоп и ясность текста, критик и редактор, конкуренты, словарь терминов, зарубежный рынок |

Основные 7 файлов занимают больше половины контекста Проекта, поэтому claude.ai может читать их фрагментами по поиску. Для большого сайта лучше «быстро: <тема>» по одной теме за раз.

## Как пользоваться

| Напишите | Что будет |
|---|---|
| `полное ревью example.ru` | 3 вопроса брифа, чтение страниц, просьба прислать скриншоты, все темы по очереди, перепроверка, отчёт |
| `быстро: мобильная example.ru` | Одна тема на 1–3 страницах |
| `конкуренты example.ru` | Разбор 3–6 конкурентов |
| `проверка правок` + файл реестра или прошлого отчёта | Что исправлено, что нет, что сломалось |

Скриншоты: главная и 2–3 важные страницы на ширине 390 (телефон) и 1440 (компьютер), первый экран и вся страница.

## Чем отличается от плагина

| | Плагин Claude Code | Проект claude.ai |
|---|---|---|
| Замеры | скрипты: скорость, контраст по пикселям, ширины экрана от 280 до 1920, клавиатура, cookie, заголовки | по скриншотам и коду страницы, оценочно |
| Агенты | до 6 одновременно, скептик и критик — отдельные агенты | один диалог, темы по очереди |
| Защита сайта | запросы, кроме GET, обрываются, счётчики заблокированы | Claude только читает страницы и формы не отправляет |
| Отчёт | HTML + Excel (+PDF) с кадрами и рамками | артефакт HTML, реестр — таблицей или файлом Excel |

## Обновление

Файлы `knowledge/` и `knowledge-extra/` собирает скрипт из справочников плагина, руками их не правят:

```
node plugins/revizor/scripts/build-claude-ai.mjs
```

`--check` проверяет, что файлы свежие и в бюджете 400 000 знаков (так делает CI). После обновления перезагрузите файлы в Проект.

Лицензии частей справочников — в [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).
