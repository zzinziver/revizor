# Эталонные реестры для проверки читателя xlsx

Файлы для тестов `recheck.mjs --from <xlsx>` и `memory.mjs --from-registry <xlsx>` (формат реестра — plugins/revizor/knowledge/report-structure.md, раздел «Реестр `registry.xlsx`»). Замечания вымышленные, по демо-сайту «Кофейня „Зёрна“».

| Файл | Что внутри |
|---|---|
| `registry-owner.xlsx` | Реестр для аудитории owner: листы «Замечания» (12 столбцов, см. `plugins/revizor/knowledge/report-structure.md`, раздел 8), «По месту правки», «Сводка» с формулами, «Как читать», скрытый `_revizor`. Все статусы «новое». |
| `registry-team.xlsx` | То же для team: в конце «Линзы, Метод, Норма, Уверенность, uid». |
| `registry-edited.xlsx` | Что остаётся после человека и офисного пакета: статусы вписаны руками в другом регистре («Исправлено», «В РАБОТЕ», «Исправлено » с пробелом), комментарии, свой столбец «Ответственный» посередине, заголовки переименованы («Статус » с пробелом, «Комментарий заказчика», «Проверено (дата)»), «Тема» записана rich text из двух кусков, тексты «Что на сайте» — inline-строки (`t="inlineStr"`), порядок листов другой («Сводка» первой), пути в связях абсолютные (`/xl/worksheets/…`). |
| `expected-read.json` | Что читатель обязан достать из каждого файла: uid, rid, статус, комментарий, дату проверки, пользовательские столбцы. |
| `make-fixtures.mjs` | Пересобрать файлы: `node make-fixtures.mjs` (нужен Node 22+, зависимостей нет). |

Строка метаданных на листе `_revizor` — последняя: `_meta | site=… | run_date=… | plugin_version=… | schema_version=…`.

## Чего здесь нет

**Настоящих файлов, пересохранённых в Excel и LibreOffice, здесь нет.** `registry-edited.xlsx` только повторяет известные отличия таких файлов, собранный нашим же кодом. Перед выпуском добавьте два файла руками:

1. Откройте `registry-owner.xlsx` в Excel, проставьте статусы и комментарии как у `registry-edited.xlsx` в `expected-read.json`, вставьте столбец «Ответственный» перед «Трудоёмкость», сохраните как `registry-owner.excel.xlsx`.
2. То же в LibreOffice Calc → «Сохранить как» → формат Excel 2007–365 → `registry-owner.libreoffice.xlsx`.
3. Допишите оба файла в `expected-read.json` (раздел `files`) с теми же ожидаемыми статусами.

Скрытый лист `_revizor` при этом должен остаться скрытым и целым: по нему recheck находит находки по `uid`.

# Страницы для быстрых проверок скриптов (`pages/`)

`node plugins/revizor/scripts/selftest.mjs --units` поднимает сервер на этой папке (порт 0, только 127.0.0.1), снимает четыре страницы `snapshot.mjs` на 390 и 1440, трижды вызывает `probe.mjs` и сверяет ответы. Около 2 минут, свой RUN в `<out>/units/`, итог — `SELFTEST UNITS PASS` и код 0.

| Файл | Что проверяется |
|---|---|
| `fill.html` | `probe --fill "#q=5,#f1=77,#f2=77"`: поля «Как к вам обращаться» и «Номер для связи» стоят в блоках без `<form>` и опознаются только по подсказке — оба `refused: contact_field`; поле калькулятора `#q` заполняется, итог 540 г → 1350 г. |
| `docs/offer-noenc.pdf` | Шрифт Type1 Helvetica без `/Encoding`: `doc_text` — настоящий текст («Refund of a prepaid order within 14 days…») или честный отказ (`doc_text: null` и `doc_text_why`), мусор вида `falsefalse…` — провал. |
| `docs/offer-winansi.pdf` | Тот же текст с `/Encoding /WinAnsiEncoding` читается целиком. |
| `crash.html` | Якорь `#sale-50%` не роняет сбор ссылок (`links@*: ok`, у него `anchor_ok: false`, у `#order` — `true`); страница без `<header>`: `<main>` не становится шапкой. |
| `noviewport.html` | Страница без meta viewport на 390: `no_viewport_zoom` < 1, основной текст на экране ≈ 6 px. |
| `cases.html` | Текст из shadow DOM в основном содержимом `text.md`; аккордеон без aria и классов, неактивные слайд и вкладка — «[свёрнуто]»; ссылка в `content-visibility:auto` видима; образец роли «текст» в `fonts.json` — не скрытый слайд. |
| `extra.html` | Строки сайта, похожие на разметку `text.md` («# …», «[скрыто] …», «**[Подвал]**», «<!-- …»), экранированы `\`; блок с анимацией появления — обычная строка; прозрачный слой за правым краем — «[невидимо]». |

Плюс: ни одного не-GET к серверу фикстур (свой счёт по журналу и `serve.mjs --stats --fail-on-writes`). Ссылки страниц ведут в никуда (`/menu`, `/order`) — 404 здесь нормальны. Новый случай: страница в `pages/`, её имя в `UNIT_PAGES` и проверка в `COLLECTOR_UNIT_CHECKS` или `UNIT_CHECKS` в `selftest.mjs`.
