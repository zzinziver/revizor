# Профиль `standard` — общая гигиена

Профиль по умолчанию. Это нормы, которые подходят любому сайту и любому владельцу. Вкус ревьюера здесь — только вариант на решение владельца. Строгий вкус — в `strict.md`, он добавляется поверх этого профиля.

## 1. Основа

- Поведение, страховка, важность, формат — `core.md`; язык отчёта — `tone.md`.
- Сайт должен доказать, что он хорош: без похвалы по умолчанию, сильная сторона — только с цифрой и доводом.
- Факты владельца — истина; решения владельца — не ошибки; отклонённое не предлагается.
- Каждая находка: цифра, норма, место, ширина, состояние, сценарий поломки и «чем проверено». Правка выполнима на платформе сайта.
- Противовес строгости: без сценария, где человек спотыкается или бизнес теряет, находки нет. Пустой список при заполненных `clean_checks` — нормальный итог.

## 2. Нормы для линз

| Тема | Как в `standard` |
|---|---|
| Вкус («не нравится», «бедновато» без сравнения, шаблонность без примет из `visual-52`) | `taste: true`, P3, вариантом на решение владельца; одной строкой на тему |
| Шаблонный вид «как у сайтов из генератора» (приметы `visual-52`: палитра — `color-35`, шрифты — `typography-36`, компоненты и картинки — `visual`) | наблюдаемый признак, `taste: false`: P3 за примету с кадром и полем замера; 3 и больше примет на сайте — одна сводная находка P2 у `visual` со списком примет и кадрами. В отчёте — «шаблонный вид», без «сделано нейросетью». Шрифты и палитры из этих списков в правках не предлагать |
| «Ниже уровня ниши» | находка только с кадром конкурента из `rivals/`; P2–P3 |
| Шрифты | нормы: кириллица и глифы, кегль основного текста от 16 px на телефоне, поля от 16 px, межстрочный 1,5–1,75, строка 35–75 знаков, загрузка шрифтов, лицензии. Выбор гарнитуры — вкус, кроме шрифтов по умолчанию у генераторов (`typography-36`) |
| Цвет | контраст текста 4,5:1 (крупный 3:1), не-текст 3:1, цвет не единственный признак, тёмная тема ОС не ломает сайт. Тёмный фон, тонкий и мелкий текст дополнительно по APCA: основной текст Lc 75 (`color-39`; на пути к действию P2, остальное P3). Выбор палитры — вкус, кроме палитр-примет (`color-35`) |
| Тексты сайта | нейрослоп и канцелярит по уровням словаря (`language/ru-ai-markers.md`); оговорки-сомнения — P3, а у главного обещания и в первом экране — P2; машинные следы и заглушки — P0 |
| Длинные тексты | абзац длиннее 6 строк на 390 px — P3; одна мысль на нескольких страницах — P2 |
| Диапазоны | «2–3 дня» с коротким тире — норма русской типографики |
| Изменения главной | важность по влиянию на путь к действию |
| Анимация | движение размеров и положения — через `transform` и `opacity`, без перерасчёта раскладки; `transition: all` — нет; настройка «уменьшить движение» учтена. Смена цвета или тени при наведении — норма. Нужна ли анимация вообще — вкус |
| Правки | эволюционные: типографика → отступы и ритм → цвет → анимация → первый экран → замена блока. «Переделать всё» не предлагать. Без согласия не трогать адреса страниц, подписи меню, поля форм, логотип, юридические тексты |
| Проверка правки подменой | 390 и 1440; правка шапки — ещё бургер на 375 и 834; любая CSS-правка — ещё переполнение на 320 и 440 (`core.md` §4 п. 7) |
| Перепроверка после публикации (`recheck`) | CDN несколько минут отдаёт то старую, то новую версию: перемер — после того, как на странице виден новый код; иначе `not_fixed` будет ложным |

## 3. Процесс

- Бриф — одним окном, не больше 4 вопросов, только то, чего нет во флагах, настройках и `site-memory`.
- Отчёт — по аудитории (`tone.md` §1). Оценки — по флагу `--scores`.
- После отчёта — итог в чат 5–8 строк и подсказка про `/revizor:recheck` и `/revizor:rivals`. Разбора по одному нет.
- Конкуренты в полном ревью — лёгкий снимок 3 сайтов для планки ниши (`--no-rivals` выключает).
