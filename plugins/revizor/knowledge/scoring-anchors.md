# Якоря оценок «X из 10»

Для `scorer` (комиссии `strict` и `market`, флаг `--scores`). Оценки бывают только в отчёте владельцу и своей команде; для чужой команды — никогда. Без якорей модель ставит «по ощущению» 7–8, а обычный живой сайт получает 4–6 из 10. Якоря ниже — четыре вымышленных сайта, по одному на ступень 3, 5, 7, 9.

## 1. Шкала

| Балл | Что значит |
|---|---|
| 1–2 | сломано и мешает бизнесу: заявку не оставить, сайт не открывается или врёт о ценах |
| 3–4 | много серьёзного: есть P0 или пачка P1 |
| 5–6 | работает с заметными потерями |
| 7–8 | хорошо, точечные улучшения |
| 9–10 | эталон для малого бизнеса в нише, лучше конкурентов по кадрам |

Шаг — 0,5. Решают серьёзность и масштаб, число мелочей почти ничего не значит: десять опечаток в подвале весят меньше одной неверной цены на главной.

## 2. Десять направлений

Ключи `areas` в `scores-<комиссия>.json`. Комиссия работает до редактора по `report/digest.md`: находка относится к направлению своей линзы (столбец `lens`), одна находка — одно направление, чтобы проблема не снижала оценку дважды.

| Ключ | Направление | Линзы |
|---|---|---|
| `product` | Продукт и путь к действию | product, visitor, forms, ecommerce |
| `ux` | Сценарии и навигация | ux, i18n |
| `visual` | Дизайн, шрифты, цвет | visual, typography, color |
| `mobile` | Мобильная версия и совместимость | mobile |
| `a11y` | Доступность | a11y |
| `copy` | Тексты и факты | copy, facts |
| `seo` | Поиск: техника и содержание | seo-tech, seo-content |
| `perf` | Скорость | perf |
| `stability` | Стабильность и код | stability |
| `security` | Безопасность, приватность, право | security, privacy, legal |

Линза не отработала (нет файла или `failed`) — ключа направления в `areas` нет: `null` валидатор не примет. В `rationale.<ключ>` — строка «не оценено: …».

## 3. Потолки (жёсткие)

1. В направлении есть P0 — не выше **4**.
2. В направлении 3 и больше P1 — не выше **6**.
3. **8 и выше** — только если в направлении нет P0 и P1 **и** есть довод «лучше ниши» с кадром конкурента из `rivals/<host>/` (ссылкой на кадр в `rationale`). Нет снимков конкурентов — потолок 7,5.
4. Решения владельца (`owner_decisions`), вкусовые находки (`taste`) и находки с тегом `profile:strict` оценку не снижают: оценки сайтов, проверенных в разных профилях, остаются сравнимыми.
5. Без полевых данных CrUX `perf` не выше 7: лабораторные цифры относительные. На медленной машине (`machine_slow`) лабораторные цифры сами по себе не опускают `perf` ниже 4.

Самопроверка оценщика: `overall` выше 7 при P0 в отчёте — перепроверь потолки.

## 4. Две комиссии

- **strict** — абсолютная шкала 2026 года: Core Web Vitals, WCAG 2.2 AA, требования Яндекса и Google, эвристики удобства, законы рынка. Конкурентов не учитывает, кроме правила потолка 8+.
- **market** — против реальных конкурентов ниши (`rivals/`, `rivals_light`) и задачи «довести посетителя до заявки». Сайт на уровне ниши — 5–6, лучше ниши по кадрам — выше.
- Комиссии работают параллельно и не видят оценок друг друга. Расхождение итога на 1,5 балла и больше `report.mjs` показывает пояснением.

## 5. Как ставить

1. По каждому направлению прочитать находки (`show.mjs --lens …`) и сильные стороны.
2. Найти в таблице §6 ближайший якорь по сути проблем; число находок не решает. Поправка ±0,5, если сайт между якорями.
3. Применить потолки §3.
4. `rationale` — 2–4 предложения на направление: какой якорь ближе и почему, главные находки по `id` (`mobile-03`), довод для 8+. Номеров вида `P0-01` до редактора нет: `id` в номера переводит `report.mjs`.
5. `overall` — среднее по оценённым направлениям, одна цифра после запятой.
6. `top_drivers` — 3–5 `id` находок, сильнее всего опустивших оценку.
7. `anchors_used` — строка: какие якоря взяты по направлениям («product 5, mobile 3, остальные 5–7»).

```json
{ "overall": 4.8,
  "areas": { "product": 4, "ux": 5, "visual": 5.5, "mobile": 3.5, "a11y": 4, "copy": 6, "seo": 5, "perf": 5, "security": 5 },
  "rationale": { "mobile": "Ближе к якорю 3: на 390 px меню не нажимается (mobile-01), на 360 px страница уезжает вбок (mobile-03). Потолок 4 из-за P0.",
                 "stability": "не оценено: линза stability упала, находок нет" },
  "top_drivers": ["mobile-01", "mobile-03", "product-02"],
  "anchors_used": "mobile 3, product и a11y 3–5, остальные 5" }
```

## 6. Якоря по направлениям

Четыре вымышленных сайта:
- **Якорь 3 — «Шиномонтаж у трассы»**: визитка на конструкторе, 5 страниц, шаблон без доработки.
- **Якорь 5 — «Языковая школа в спальном районе»**: обычный живой сайт на WordPress, 20 страниц.
- **Якорь 7 — «Пекарня с доставкой»**: аккуратный сайт с каталогом и корзиной, 30 страниц, свои фото.
- **Якорь 9 — «Ветеринарная клиника»**: лучший сайт в своей нише и городе, онлайн-запись, сравнение с 5 конкурентами по кадрам.

## 7. Частые ошибки комиссий

- Оценка по числу находок: 40 мелочей в `copy` — это всё ещё около 6.
- Похвала аккуратности: «чисто и современно» без замеров — не довод для 7+.
- Двойной счёт: контраст кнопки снижает `visual` (линза `color`), а `a11y` снижают только находки линзы `a11y`.
- 8+ без кадра конкурента.
- Оценка за то, чего нет в брифе: магазинные ожидания к визитке, требования ЕС к сайту для одного города.
