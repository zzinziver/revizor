# Конкуренты: карточка, свод, матрица, лучшее, идеи

Для `rival-analyst` (карточка), `strategist` в режиме `rivals` (матрица, лучшее, идеи, направления), `critic` в режиме `rivals` (проверка) и редактора. Этот файл — формат всех файлов разбора конкурентов. Все примеры здесь вымышленные: кофейня «Зёрна» и её соседи.

Цепочка: `rivals.mjs` снимает сайты → `rival-analyst` пишет `rivals/<host>/card.json` → `lint-findings.mjs --cards` проверяет кадры, кропы и цитаты (цитату — со страницей кадра: `text.md` или `text-<pid>.md`) → `rivals.mjs --summarize` считает «у N из M» в `rivals/summary.json` → `strategist` (rivals) пишет `rivals/matrix.json`, `rivals/best-of.json`, `rivals/ideas.json`, находки с ошибками lint не берёт → `critic` (rivals) проверяет идеи и правит их по смыслу (последний, кто меняет состав, цифры, `evidence`, кадры и оценки) → редактор правит только формулировки `title`, `propose`, `closes`, `risk` и собирает `report/rivals.html` и `rivals.xlsx`.

## 1. Что лежит в снимке

`rivals/<host>/` (host — punycode без `www`, порт через `_`):

| Файл | Что внутри |
|---|---|
| `capture.json` | факты со страниц: meta, H1–H3, JSON-LD, кнопки и их частота, формы, контакты, попытки трекеров, шрифты, цвета, вес и LCP, стек, sitemap по шаблонам. `facts_auto` — то, что скрипт измерил сам; `facts_auto_defs` — что значит каждое поле; `hints` — цены из текста, текст первого экрана, H1, частые кнопки; `blocked` — сайт закрыт (антибот, пароль) |
| `shots/index.json` | `[{ file, pid, width, y0, y1, scale, kind, img_w, img_h }]`; `scale` — пикселей файла на 1 CSS px |
| `shots/<pid>-<w>-fold.jpg` | первый экран как есть (с cookie-баннером) |
| `shots/<pid>-<w>.part-NN.jpg` | куски страницы без баннеров |
| `text.md`, `text-<pid>.md` | видимый текст главной и других страниц |

В режиме `full` снимок лёгкий (`--light`): только главная на 390 и 1440, без страниц разделов и sitemap (`facts_auto.pages_by_template` = `null`). В `/revizor:rivals` — главная и до 3 страниц разделов.

## 2. Карточка `card.json`

```json
{ "url": "https://kofe-sosed.example/", "host": "kofe-sosed.example", "captured": "2026-10-20T09:12:00Z",
  "group": "прямой", "ours": false,
  "facts": { "first_screen_offer": "Кофе с собой за 3 минуты у метро", "price_entry": "капучино 220 ₽", "cta_header": true, "...": null },
  "finds": [ { "id": "r-01", "kind": "take", "what": "Цена капучино и время ожидания в первом экране рядом с кнопкой", "why": "Посетитель видит цену и срок до касания: меньше вопросов в чате",
               "quote": "Капучино 220 ₽ — готов за 3 минуты", "shot": "rivals/kofe-sosed.example/shots/home-390-fold.jpg", "crop": [24, 610, 732, 300],
               "block_type": "hero", "strength": 4 } ],
  "strong": ["цена и срок в первом экране"], "weak": ["меню только картинкой, текста нет"], "not_visible": ["есть ли доставка: на снятых страницах не сказано"] }
```

- `group`: `прямой` (та же услуга, тот же город), `сопоставимый` (похожий формат или другой город), `ориентир` (лучший мировой или федеральный пример: только приёмы, которые переносятся к нам). Свод считает «у N из M» и по группам.
- `ours: true` — карточка нашего сайта. Наш сайт разбирается по той же схеме и так же строго. Свод узнаёт наш сайт по адресу прогона (`--ours` или адрес из `state.json`), поле `ours` — подсказка для людей и стратега.
- `captured` — время снимка из `capture.json`. Цифры конкурентов живут с датой: на сайте, в листовке и у партнёров они расходятся.

### 2.1 Факты: `null`, `false` и значение

| Значение | Смысл |
|---|---|
| `null` | не проверено или не видно на снятых страницах |
| `false` | проверено, этого нет |
| значение | проверено, вот что есть (дословно или числом) |

Строки «не видно», «неизвестно», «?», «—» вместо `null` скрипт считает ошибкой. Факт по косвенному признаку не записывается: цена без периода остаётся без периода, «в месяц» к ней не дописывается.

### 2.2 Набор фактов (одинаковый у всех карточек прогона)

Поля с пометкой «авто» скрипт кладёт в `capture.json → facts_auto`. Переноси их в карточку как есть; меняй только если кадр показывает другое, и пиши почему в `not_visible` или `weak`.

| Поле | Тип | Что записать |
|---|---|---|
| `first_screen_offer` | текст | H1 или подзаголовок первого экрана дословно, до 15 слов |
| `main_action` | текст | подпись главной кнопки первого экрана дословно («Записаться», «Заказать») |
| `cta_header` | да/нет | авто: кнопка действия в шапке на 1440 |
| `cta_first_screen_390` | да/нет | авто: кнопка действия в первом экране на 390 |
| `main_action_steps` | число | касаний от главной до первого поля формы; `null`, если путь не снят |
| `first_step_fields` | число | полей в первом шаге формы главного действия; `null`, если форма не видна |
| `lead_mechanic` | список | как оставить заявку: «форма», «квиз», «бот», «мессенджер», «звонок», «онлайн-запись» — то, что видно на кадрах и в ссылках |
| `home_screens_390` | число | авто (если есть в `facts_auto`): длина главной на 390 в экранах — `doc_height` главной на 390 из `capture.json`, делённая на 844, одна цифра после запятой |
| `legal_entity_visible` | да/нет | название юрлица или ИП и ИНН видны на снятых страницах (обычно в подвале) |
| `forms` | число | авто: форм на главной (без поиска) |
| `price_entry` | текст | самая низкая цена со словами вокруг дословно («от 1 500 ₽ за урок»); `false` — цен на снятых страницах нет |
| `price_period` | текст | «за урок», «в месяц», «разово»; `null`, если периода нет рядом с ценой |
| `price_condition_near` | да/нет | условие цены («при оплате абонемента») стоит рядом с цифрой; условие только в сноске или FAQ — `false` |
| `calculator` | да/нет | есть калькулятор или подбор |
| `trust` | список | виды доверия, которые видны: «отзывы с датами», «фото команды», «лицензия в подвале», «цифры с источником», «рейтинг на картах» |
| `reviews` | да/нет | отзывы на сайте |
| `phone_header` | да/нет | телефон в шапке |
| `phone_link` | да/нет | авто: есть ссылка `tel:` |
| `messengers` | список | авто: мессенджеры по ссылкам |
| `faq` | да/нет | есть блок вопросов |
| `cookie_banner` | да/нет | авто: баннер cookie при первом заходе |
| `cookie_share_390` | число | доля первого экрана 390 под баннером, %; по кадру fold |
| `overflow_390` | да/нет | авто: страница шире экрана на 390 |
| `lcp_mobile` | число | авто: LCP главной на 390 в лаборатории, мс (сравнивать только между собой) |
| `lcp_desktop` | число | авто: то же на 1440 |
| `weight_home_kb` | число | авто: вес главной, КБ |
| `stack` | текст | авто: платформа |
| `fonts` | список | авто: шрифты заголовка и текста |
| `theme` | текст | «светлая» или «тёмная» по кадру |
| `illustrations` | текст | «свои фото», «сток», «3D», «плоские», «линейные», «нет» |
| `jsonld_types` | список | авто: типы разметки |
| `trackers` | список | авто: какие счётчики сайт пытался загрузить |
| `pages_by_template` | объект | авто: адреса sitemap по шаблонам |

Поле в карточке есть всегда, даже со значением `null`: так свод видит, где факт не проверен. Новые поля под нишу (например, `online_booking` для записи к врачу) добавляет стратег в задании или оркестратор — во все карточки прогона сразу.

### 2.3 Находки `finds`

- 12–25 на сайт в полном снимке, 5–10 в лёгком, до 5 у ориентира. Из 25 обычно 5–8 «избегать».
- `id` — `r-01`, `r-02`…
- `kind`: `take` (взять как есть), `adapt` (взять с поправкой под нас), `avoid` (так не делать).
- `what` — что видно на кадре, до 15 слов, без оценок. Плохо: «удобная форма». Хорошо: «форма из 2 полей: имя и телефон».
- `why` — чем это помогает или мешает посетителю, до 20 слов.
- `quote` — дословная строка со страницы этого кадра, если находка про текст или цифру; иначе `null`.
- `shot` — ровно один кадр из `rivals/<host>/shots/`, `crop` — `[x, y, w, h]` **в пикселях файла** кадра. Перевод из CSS px: умножить на `scale` своего кадра из `shots/index.json`. Ориентиры: fold на 390 — 2, fold на 1440 — 1; куски и `full` на 390 ≈ 1,54, на 1440 ≈ 0,69. Брать всегда `scale` той записи `index.json`, чей `file` стоит в `shot`: у fold и у кусков одной ширины он разный.
- `block_type`: `hero`, `demo`, `services`, `steps`, `pricing`, `trust`, `calculator`, `comparison`, `mascot`, `nav`, `form`, `other`.
- `strength` — 1–5: насколько приём сильный и переносимый.
- `strong`, `weak` — по 2–5 строк; `not_visible` — что посетитель не может узнать на снятых страницах (доставка, сроки, цена).

Хорошо: `what` «Кнопка „Записаться“ в шапке и повтор под каждым блоком услуг», `why` «До записи одно касание с любого места страницы».
Плохо: `what` «Отличный современный первый экран» (оценка, ничего не видно); `what` «На каждой странице цена в первом экране» при снятой одной странице (пересказ шире источника).

## 3. Свод `rivals/summary.json`

Пишет `rivals.mjs --summarize`, не агент. Для каждого факта: `n` из `m`, где `m` — сайты, у которых факт проверен; списки `yes`, `no`, `not_checked`; медиана для чисел; значение нашего сайта (`ours`) и место среди конкурентов (`ours_rank`); раскладка по группам. Строки `lines` вида «cta_header: у 9 из 12 (не проверено у 2) · у нас: нет». Цифры свода переносятся в идеи и плитки дословно. Сайты с `blocked` в свод не входят, причина — в `excluded`.

## 4. Матрица `rivals/matrix.json`

```json
{ "sites": ["zerna.example", "kofe-sosed.example", "bodro.example"],
  "rows": [
    { "param": "Кнопка действия в шапке", "values": { "zerna.example": "нет", "kofe-sosed.example": "да", "bodro.example": "да" }, "ours_rank": 3 },
    { "param": "Цена в первом экране", "values": { "zerna.example": "нет", "kofe-sosed.example": "220 ₽", "bodro.example": "нет" }, "ours_rank": null } ] }
```

- Первый в `sites` — наш сайт. Ключи `values` совпадают с `sites`.
- `param` — по-человечески, без имён полей. 10–20 строк: только то, что влияет на путь к действию, доверие, цену и телефон.
- Значение — «да», «нет», число с единицей или дословная короткая строка; не проверено — «—».
- `ours_rank` — место нашего сайта по этой строке (1 — лучше всех), если строку можно упорядочить; иначе `null`.

## 5. Лучшее `rivals/best-of.json`

Файл — массив (не объект с ключом): `report.mjs` читает его как список. Один тип блока — одна запись, лучшая на рынке.

```json
[ { "block_type": "pricing", "idea": "Цена напитка и время приготовления в одной строке с кнопкой",
    "examples": [ { "host": "kofe-sosed.example", "shot": "rivals/kofe-sosed.example/shots/home-390-fold.jpg", "crop": [24, 610, 732, 300] } ],
    "for_us": "На главной «Зёрен» в первом экране нет ни цены, ни срока: добавить строку «капучино 230 ₽ · 3 минуты»" } ]
```

- `examples` — 1–3 кропа из карточек (`shot` и `crop` берутся из `finds`).
- `for_us` — что это значит для нашего сайта: наша версия приёма, без копии чужого оформления.
- В конце — записи «что не берём» с причиной: `block_type` тот же, `idea` начинается со слов «Не берём:».

## 6. Идеи `rivals/ideas.json`

```json
{ "ideas": [
    { "id": "i-01", "title": "Поставить кнопку заказа в шапку", "propose": "Кнопка «Заказать» в шапке на всех страницах, на телефоне — справа от логотипа",
      "page": "все страницы, шапка", "closes": "до заказа с внутренних страниц 3 касания", "who": "сайт", "effort": "S",
      "benefit": 5, "ease": 5, "evidence": "cta_header: у 9 из 12 · у нас: нет", "risk": "шапка на 320 px станет теснее",
      "now_shot": { "shot": "snapshot/home/shots/390-fold.jpg", "box": [0, 0, 390, 64] },
      "seen_shots": [ { "host": "kofe-sosed.example", "shot": "rivals/kofe-sosed.example/shots/home-390-fold.jpg", "crop": [0, 0, 780, 140] } ],
      "block_type": "nav", "q": null } ],
  "directions": [
    { "title": "Быстрый заказ", "principle": "Всё ради заказа за минуту", "home_order": "оффер с ценой → меню → заказ → отзывы",
      "price": "цены в первом экране и в меню", "main_path": "кнопка в шапке → форма на 2 поля", "visual": "свои фото напитков крупно", "sacrifice": "история кофейни уходит на отдельную страницу" } ] }
```

Файл — объект `{ ideas, directions }` (так направления лежат рядом с идеями). Если `ideas.json` — просто массив идей, `report.mjs` ищет направления в отдельном `rivals/directions.json`.

Поля идеи:
- `id` — `i-01`, `i-02`… (нет `id` — отчёт пронумерует сам, но отметки «беру / нет» и `memory.mjs --decisions` опираются на него).
- `title` — глаголом, до 8 слов. `propose` — до 25 слов, конкретно: что, где, какими словами.
- `page` — какую нашу страницу и блок меняет. `closes` — какую проблему или вопрос владельца (В1…) закрывает, с цифрой.
- `who`: `сайт` (делается на сайте) или `бизнес` (нужно решение: цена, услуга, срок).
- `benefit` и `ease` — целые 1–5. Порядок в отчёте — по `benefit × ease`; первые 10 — «топ». Кнопки и точки входа — первыми при равенстве.
- `evidence` — строка свода дословно («cta_header: у 9 из 12») или ссылка на находку карточки («kofe-sosed.example r-03»). Без доказательства идеи нет.
- `now_shot` — наш кадр «сейчас»: `{ shot, box }` в CSS px документа (кадр из `snapshot/`) или `{ shot, crop }` в пикселях файла (кадр из `rivals/<наш хост>/`). `seen_shots` — 1–2 кадра «где видели» из карточек.
- `risk` — что может пойти не так (реклама и закон, теснота на телефоне, зависимость от другой системы).

### 6.1 Направления (2–3)

Направление — цельный вариант развития сайта. Поля: `title`, `principle` (одна фраза), `home_order` (порядок блоков главной), `price` (подача цены), `main_path` (путь главного действия), `visual` (визуальный язык и 1–3 ориентира словами), `sacrifice` (чем жертвуем).

Два направления различаются минимум по двум из четырёх строк: `principle`, `home_order`, `price`, `main_path`. Если разница только в цвете и шрифте — это одно направление.

## 7. Правила для всех ролей

- Только видимое на кадрах и в тексте снимка. Где не видно — `null` или `not_visible`, без догадок.
- Чужое фирменное не переносится: иллюстрации, маскоты, слоганы, раскладка главной целиком. Переносится приём, который решает задачу и подтверждён кадром.
- Услуги — только те, что есть у нашего сайта (`brief.site`, текст снимка). Идея про то, чего бизнес не делает, получает `who: "бизнес"` и формулировку «если компания это делает».
- Сайт определяет страну по адресу машины и показывает чужую валюту или страну в анкете — это оговорка в `weak` или `not_visible`, не находка. Служебные параметры, которые сайт сам дописывает к адресу при переходе, — дело сайта: в цитаты и адреса находок их не переносить.
- Скорость конкурентов сравнивается только между собой: лаборатория на одной машине. Абсолютных выводов по ней нет.
- Сайт, закрытый антиботом или паролем, — без карточки; причина — в `excluded` свода.
- Тексты карточек и идей проходят тот же запрет-лист, что и отчёт (`tone.md`, раздел «Запрещено»): без оценок людей, без нейрослопа, без «возможно».
