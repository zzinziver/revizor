# Зарубежный рынок: Google, ИИ-ассистенты, право ЕС, Великобритании и США, сроки, ожидания посетителя

**Кто читает:** `seo-tech`, `seo-content`, `legal`, `privacy`, `forms`, `a11y`, `copy`, `facts`, `product`, `ecommerce`, `ux`, `mobile`, `visitor`, `i18n`, `scout`, `strategist`, `critic` (режим `strategy`), скептик раздела «право».
**Когда:** `brief.market.value = "intl"` — этот файл. `"mixed"` — этот файл и `ru.md` (отдельного `markets/mixed.md` нет): каждый раздел — для своей части аудитории. `"ru"` — только `ru.md`.
**Чьё право:** по `brief.market.countries` и признакам на сайте: валюта, язык, адрес, доставка, телефоны. Пустой список — право не угадывать: вопрос в `open_questions`. Нормы ЕС брать, когда видна аудитория ЕС (цены в €, язык страны ЕС, адрес или доставка в ЕС). Сайт на английском из РФ для зарубежных клиентов — нормы страны клиентов плюс ПДн по `ru.md`, если оператор в РФ.
**Сверено:** 24.10.2026. Сайт EUR-Lex при сборке не отдавал текст роботу, поэтому нормы ЕС сверены по страницам Еврокомиссии, регуляторов, Google и юридическим обзорам; перед находкой агент `legal` открывает текст на EUR-Lex или на сайте регулятора.
**Пометки:** **«сверить редакцию»** — источники расходятся или первоисточник не открылся; без своей сверки такую норму в находку не брать. **«Практика, в справке нет»** — у поисковика правило не описано; в находке `confidence: "medium"` или ниже.

## 1. Поиск: Google (и Bing)

| Тема | Норма | Где смотреть |
|---|---|---|
| title | Лимита нет, Google обрезает по ширине устройства; рабочая норма 50–60 знаков. Уникален, без шаблонов, отличающихся одним словом, без повторов ключей; бренд в начале или в конце через «—», «:», «\|» ([title links](https://developers.google.com/search/docs/appearance/title-link)) | `seo.json → items[].title`, `site.title_duplicates` |
| description | Числа нет; рабочая норма 150–160. Google может собрать сниппет сам из текста | `items[].description` |
| robots.txt и noindex | Disallow запрещает обход; страница по внешним ссылкам может попасть в индекс. Убрать из выдачи — `noindex` (страница открыта для обхода) | `site.robots`, `items[].robots` |
| canonical | Подсказка вместе с редиректами, sitemap и внутренними ссылками. Self-canonical без параметров | `items[].canonical.*` |
| Параметры адресов | Clean-param Google не поддерживает: canonical на чистый адрес, не ссылаться на адреса с параметрами, фасеты — canonical или noindex | метки — `items[].links.tracking_params` (только `utm_`, `yclid`, `gclid`, `fbclid`, `from`); прочие параметры — `seo.json → items[].links.param_links` (`pagination`, `sort`, `filter`, `other`, `samples` до 5; флаг `param-links`); запасной путь и sitemap — адреса с `?` в `measure/links.json → items[]` (`internal: true`) |
| hreflang | Взаимные ссылки во всех версиях, `x-default`, коды языка ISO 639-1 и региона ISO 3166-1 (`en-GB`, не `en-UK`), каждая цель отдаёт 200 и сама себе canonical. Один способ: `<head>`, sitemap или заголовок | `items[].hreflang`, `site.hreflang` (владелец — `i18n`) |
| Разметка | FAQ-сниппеты не показываются с 07.05.2026, документацию сняли 15.06.2026. 09.09.2025 сняли документацию Course info, Estimated salary, Learning video, Special announcement, Vehicle listing; 06.01.2026 — Practice problem. ClaimReview сворачивается (баннер с 12.06.2025). **Book actions работает**: баннер об устаревании убрали 05.11.2025. Course list (`Course` + `ItemList`, карусель курсов) работает для страниц на английском во всех регионах ([Course list](https://developers.google.com/search/docs/appearance/structured-data/course)). Крошки в выдаче — только на компьютере с 22.01.2025 ([журнал изменений](https://developers.google.com/search/updates)) | `items[].jsonld.*` |
| Core Web Vitals | p75 полевых данных: LCP ≤ 2,5 с, INP ≤ 200 мс, CLS ≤ 0,1; INP заменил FID в 2024 ([web.dev](https://web.dev/articles/vitals)). Лаборатория — подписывать «лаборатория» | `measure/perf.json` |
| Мобильная версия | Google индексирует по мобильной отдаче: текст, ссылки и разметка на 390 px не беднее, чем на 1440 | `page.json → parity` |
| JS и рендер | Google рендерит JS с задержкой; ИИ-боты обычно JS не исполняют. Пустой `#root` в исходном HTML — P1 для сайта, которому нужен поиск; P0 — только с доказательством выпадения из индекса (Search Console владельца) | `items[].text.js_only`, `items[].h1.raw_count`, `site.bots` |
| Спам-правила | Cloaking, doorway, expired domain abuse, hidden text, keyword stuffing, link spam, scaled content abuse (массовые страницы ради позиций, в том числе ИИ-тексты без пользы), site reputation, thin affiliation и др. ([spam policies](https://developers.google.com/search/docs/essentials/spam-policies)) | `site.bots.bots[].spam_only_for_bot`, `items[].spam` |
| ИИ-функции Поиска | AI Overviews и AI Mode: на уровне страницы — `nosnippet`, `data-nosnippet`, `max-snippet`; на весь сайт — настройка в Search Console («Search generative AI control»). `Google-Extended` на Поиск не влияет ([control what you share](https://developers.google.com/search/docs/crawling-indexing/control-what-you-share)) | `items[].robots` |
| Кабинеты | Search Console, Bing Webmaster Tools; подтверждения на сайте | `site.verification` (только meta-теги на главной) |
| IndexNow | Поддерживает Bing и Яндекс; Google — нет | вопрос владельцу |

**Как применять:**
- Предлагаемые title и description — по норме Google, ключ в естественной форме в title, H1 и первом абзаце.
- «Добавьте FAQ-разметку ради сниппетов» — не правка с 07.05.2026. FAQPage, расходящаяся с видимым FAQ, — находка (разметка врёт).
- Нет meta-подтверждений Search Console и Bing на главной (флаг `verification-missing` уровня `info`) — не доказательство: сайт подтверждают ещё DNS-записью, HTML-файлом, через Google Analytics или Tag Manager. Пиши вопрос в `open_questions` («есть ли доступ к Search Console»). Находка P1 с `owner: "решение владельца"` — только если владелец ответил, что доступа нет, а сайту нужен поиск.

## 2. Видимость в ИИ-ассистентах (GEO)

| Что | Как проверить | Норма и подача |
|---|---|---|
| Доступ ИИ-ботов | `seo.json → site.robots.ai_bots` (поле `bot`; точный список — в самом замере: роботы OpenAI, Anthropic, Perplexity, Google, Apple, Common Crawl, Meta, Amazon, DuckDuckGo, Яндекса; Bytespider в замер не входит — его смотри глазами в `robots.txt`) и `site.bots` (ответ сайта роботам) | Пускать или нет — решение владельца. Находка — расхождение с намерением. Cloudflare с 01.07.2025 по умолчанию блокирует ИИ-краулеров на новых доменах ([пресс-релиз](https://www.cloudflare.com/press-releases/2025/cloudflare-just-changed-how-ai-crawlers-scrape-the-internet-at-large/)): при `pages.json → stack.cdn = "Cloudflare"` спросить владельца, знает ли он |
| Текст без JS | `items[].text.js_only`, `items[].text.raw_len` против `dom_len` | Считать, что ИИ-краулер видит только исходный HTML. Главное без JS не видно — P1 для сайта, которому нужны ответы ассистентов |
| Факты одной формулировкой | таблица фактов `facts` | Название, цены, часы, адрес одинаковы на всех страницах, в разметке и `llms.txt` |
| Прямые ответы | `text.md` | Ответ на частый вопрос — первым предложением; цены и условия — HTML-таблицей: прайс картинкой ассистент не прочтёт |
| Сущность бренда | `items[].jsonld` | Organization с `sameAs` (карточки на картах, соцсети, справочники) |
| llms.txt | `site.llms` | Не стандарт поисковиков: нет файла — не находка. Есть и устарел — находка `facts` |
| Ответы ассистентов о компании | 10–15 запросов вручную (бренд, «лучшие [ниша] в [городе]», «сколько стоит [услуга] у [бренда]») | Только если у агента есть доступ к ассистентам; иначе — в `human_checks`. Неверный факт в ответе из-за устаревшей страницы — находка сайта |

## 3. Честные сроки SEO

**Ориентир из практики: Google сроков не называет.** Цифры — без обещаний позиций и заявок: заявки зависят от спроса, цены и конверсии сайта.

| Что сделали | Когда ждать первых показов и переходов |
|---|---|
| Технические правки | после переобхода: дни — недели, точной даты нет |
| Низкочастотные и локальные запросы | 2–8 недель |
| Коммерческие запросы в конкурентной нише | 2–3 месяца и дольше |
| Контентный сайт, блог | 6–12 месяцев |
| Новый домен в конкурентной нише | дольше всех вариантов выше |
| Выход из-под ручных мер или после обновления алгоритма (core update) | после исправления и переобхода (ручные меры — запрос на проверку в Search Console) — месяцы, без даты; после core update — часто только со следующим обновлением |
| «Топ за 3 месяца», «гарантия позиций», «заявок станет на N % больше» | не бывает — в стратегию не писать |

Массовая публикация однотипных страниц — риск правила scaled content abuse. Только реальные услуги из `brief.site`.

## 4. Право

Подача: «решение владельца, лучше с юристом», `needs_decision: true`, в `norm` — акт, статья, редакция и дата сверки. Суммы штрафов не писать. P0 — только прямое нарушение с доказательством. Обязанности, которых не видно на сайте (договоры обработки, реестры, DPO), — вопросом владельцу.

### 4.4 Другие страны

Канада, Бразилия, Беларусь, Казахстан, Турция, ОАЭ и другие — свои законы о данных, языке и рекламе. По памяти их не применять: вопрос владельцу в `open_questions` («для какой страны проверять право») и `legal` с WebSearch по первоисточнику. Нормы РФ из `ru.md` к сайту другой страны не переносить.

### 4.5 Общее для всех стран

- Права на фото, шрифты, логотипы клиентов («our clients» без согласия), лицензии библиотек — P2, `needs_decision`.
- Отзывы, рейтинги, «N клиентов», «№ 1» — только с источником; поддельные отзывы прямо запрещены в ЕС (§4.1) и Великобритании (§4.2), в других странах — сверить редакцию по стране.
- Цены: валюта аудитории или явная пометка, налоги и обязательные сборы видны до оплаты, подписка показывает цену после пробного периода и как отменить.

## 5. Поправки к навыкам для зарубежного сайта

- **marketing:seo-audit:** нормы Google подходят; FID → INP; про FAQ-сниппеты — данные навыка устарели (сняты 07.05.2026); снятые типы разметки — по §1; финальный вопрос навыка «Хотите, я…» игнорировать.
- **design:accessibility-review:** брать WCAG 2.2 вместо 2.1; 2.5.5 (44×44) — уровень AAA, для AA — 2.5.8 (24×24); навык ничего не измеряет, цифры — из `measure/*`.
- **avoid-ai-writing-ru:** для английского текста — английский раздел навыка и `language/en-ai-markers.md`; правила русской пунктуации к английскому не применять.
- **legal:compliance-check** — по желанию для `legal`; его вывод проходит сверку редакции, как любая норма.
- Остальные поправки (шрифты и палитры дизайн-навыков, Title Case) — `ru.md` §5.

## 7. Ожидания посетителя зарубежного рынка: связь, оплата, цены, реквизиты, браузеры

Раздел для `product`, `visitor`, `facts`, `ecommerce`, `ux`, `mobile`. Нормы закона — со ссылкой на §4; остальное — практика рынка, в находке довод «посетитель не найдёт / не сможет», без слова «требование».

**Связь.** Телефон в международном формате (`+44 …`, `+49 …`) ссылкой `tel:`; почта на своём домене; форма. Мессенджер — по стране аудитории (в ЕС часто WhatsApp). Время ответа и часовой пояс рядом с контактами.

**Оплата (`ecommerce`, `product`).**
- Карты Visa и Mastercard, Apple Pay, Google Pay, PayPal — почти везде; местные способы — по стране: iDEAL (Нидерланды), Bancontact (Бельгия), BLIK (Польша), SEPA-перевод, оплата частями (Klarna и подобные). Способы видны до оформления.
- Подписка: цена после пробного периода, периодичность списания, как отменить — рядом с кнопкой (§4.5, для ЕС ещё §4.1 «функция отказа»).

**Цены (`facts`).**
- ЕС и Великобритания, частные лица: цена окончательная, с НДС (VAT) и обязательными сборами (§4.1, §4.2). Цена «excl. VAT» уместна только на сайте для бизнеса — с пометкой.
- США: цены обычно без налога с продаж (sales tax) — норма рынка; налог и доставка — до оплаты.
- Валюта аудитории; переключатель валют не меняет цену задним числом в корзине.
- Ставки: APR (кредит), AER (вклад) — с подписью; «0 % APR» с условиями рядом (§4.1, потребительский кредит).

**Реквизиты и доверие (`product`, `visitor`).** Название компании, адрес, номер в реестре (Company number, Handelsregister), VAT ID — на странице контактов или Imprint (§4.1, Директива 2000/31 ст. 5; ФРГ — Impressum). Отзывы со ссылкой на независимые площадки и объяснением, как их проверяют (§4.1, §4.2).

**Браузеры (`mobile`, `ux`).**
- Safari на iPhone — большая доля в США и Великобритании; долю брать на дату прогона из [StatCounter](https://gs.statcounter.com/browser-market-share), без своих цифр. Всё, что зависит от Safari, — `needs_device_check` (headless Chromium его не заменяет).
- Встроенные браузеры приложений (WebView): ссылки открывают из Instagram, Facebook, TikTok, LinkedIn, WhatsApp. Бывают заблокированы всплывающие окна и `window.open`, не сохраняются cookie, по-разному работают оплата через Apple Pay или Google Pay, переход в банк для подтверждения платежа и возврат. Сценарий «ссылка из соцсети → заявка или оплата» — в `human_checks` и `needs_device_check`.

**Язык и регион.** Язык страницы совпадает с `lang` и hreflang (`i18n`); принудительный редирект по IP без выбора — P1 (`i18n`); выбор страны и языка запоминается.
