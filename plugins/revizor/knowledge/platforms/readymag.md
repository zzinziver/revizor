# Платформа: Readymag

**Для:** `brief.platform.name = "Readymag"` (`pages.json → stack.cms`).
**Кто читает:** все линзы; больше всего — `a11y`, `mobile`, `seo-tech`, `perf`, `typography`, `visual`.
**Сверено:** 24.10.2026. Визуальный редактор для лонгридов, портфолио, презентаций и промостраниц: элементы ставятся свободно поверх страницы, раскладки для разных ширин дизайнер собирает отдельно. Хостинг — у платформы. Названия настроек при сборке по справке не сверены: правку пиши двумя путями.

## 1. Как узнать

- Адреса и файлы `readymag.com`, `readymag.website`, `rm-static` (`crawl.mjs` пишет сигнал); технический адрес проекта на домене платформы.
- Страницы проекта часто идут как «слайды» или длинный лонгрид; текст бывает картинкой или векторной графикой.

## 2. Типовые проблемы по линзам

| Линза | Что проверить | Где в замерах | Важность |
|---|---|---|---|
| `mobile` | Мобильная раскладка не собрана: на 390 px показывается уменьшенная версия для компьютера, текст мельче 12 px | `mobile.json`, `layout.json` (мелкий текст), кадры 390 | P0, если текст не читается и кнопка не нажимается |
| `mobile` | Раскладки для промежуточных ширин (768, 1024, ноутбуки) — переполнение и обрезанные блоки | `mobile.json` (переполнение по ширинам, окна ноутбуков) | P1 |
| `a11y` | Текст в картинках и SVG без альтернативы; порядок чтения скринридером совпадает с порядком создания элементов и расходится с порядком на экране | `a11y.json` (AX-дерево), `seo.json → items[].images` | P1 |
| `a11y` | Навигация по слайдам только свайпом или прокруткой, без клавиатуры (2.5.7, 2.1.1) | `a11y.json → items[].check` | P1 |
| `seo-tech` | H1 нет или текст заголовков — картинка; title и description не заданы у страниц проекта | `seo.json → items[].h1.raw_count`, `items[].title`, `items[].description` | P1 для сайта, которому нужен поиск |
| `seo-tech` | Сайт на домене платформы, без своего домена | `pages.json → final_origin` | P1 для коммерческого сайта, `needs_decision` |
| `perf` | Тяжёлые картинки и видео, анимации при прокрутке на всех экранах | `perf.json`, `mobile.json → code.motion` | P1 при LCP на 390 > 4 с |
| `typography` | Шрифты загружены пользователем: кириллица, лицензия на веб | `fonts.json` | по `typography` |
| `privacy`, `legal` | Форма платформы: куда уходят данные, зарубежный сервис (`privacy`); согласие (`legal`) | `forms.json → items[].check` | по `markets/*`; `forms` передаёт через `for_other_lenses` |

## 3. Что исправимо и где

| Задача | Где править | `fix_place` | `owner` |
|---|---|---|---|
| Мобильная раскладка | редактор: отдельная раскладка для телефона | блок CMS | владелец в CMS |
| Текст вместо картинки с текстом | заменить картинку текстовым виджетом | контент | владелец в CMS |
| title, description, OG | настройки SEO проекта и страницы (сверить в справке) | настройки платформы | владелец в CMS |
| Свой домен | настройки проекта, платный тариф | внешний сервис | решение владельца |
| Свой код (разметка, счётчики) | виджет кода или вставка в настройках проекта (сверить в справке) | шаблон | разработчик |

## 4. Ограничения платформы (P3 «платформа»)

- Сервер, заголовки ответа, `robots.txt`, структура адресов.
- Свободная раскладка: семантика заголовков и порядок чтения ограничены возможностями редактора. Если нужной настройки нет — P3 с обходным путём (дублировать смысл текстом, alt у картинок).

## 5. Ложные срабатывания

- Абсолютное позиционирование и отдельные раскладки — устройство платформы; находка только то, что видит посетитель на конкретной ширине.
- Длинная страница-лонгрид — формат платформы, «простынёй» её не считать: оценивать читаемость и путь к действию.
