# Платформа: Wix

**Для:** `brief.platform.name = "Wix"` (`pages.json → stack.cms`).
**Кто читает:** все линзы; больше всего — `perf`, `seo-tech`, `mobile`, `a11y`, `forms`, `product`.
**Сверено:** 24.10.2026. Хостинг и движок платформы: сервер и код страницы владельцу недоступны, правки — в редакторе и настройках.

## 1. Как узнать

- Файлы с `static.wixstatic.com`, `static.parastorage.com`; заголовок `x-wix-request-id`; технический домен `*.wixsite.com`.
- Отдельная мобильная раскладка в редакторе: элементы бывают скрыты только на телефоне или только на компьютере.

## 2. Типовые проблемы по линзам

| Линза | Что проверить | Где в замерах | Важность |
|---|---|---|---|
| `product` | Сайт на бесплатном тарифе: рекламная плашка платформы и адрес `*.wixsite.com` — минус доверию | кадр fold, `pages.json → final_origin` | P1 для коммерческого сайта |
| `perf` | Много скриптов платформы и запросов; потолок скорости задаёт движок | `perf.json` | P3 «платформа»; наше (тяжёлые картинки, видео, лишние приложения) — по влиянию |
| `perf` | Сторонние приложения из магазина приложений грузят свои скрипты на каждой странице | `perf.json` (сторонние), `headers.json → items[].third_party_hosts` | P2 |
| `mobile` | Мобильная раскладка собрана отдельно: на телефоне скрыты блоки, кнопка действия или цена | `page.json → parity` (текст 390 против 1440), кадры | P1, если скрыта кнопка или цена |
| `seo-tech` | Заголовки: тег H1–H6 задаётся у текстового элемента; часто H1 нет или их несколько | `seo.json → items[].h1.*` | P1–P2 |
| `seo-tech` | Старые адреса после переделки без редиректов (404 на ссылках из поиска) | `links.json`, вопрос владельцу | P2 |
| `a11y` | alt у картинок по умолчанию пустой или имя файла; порядок фокуса по раскладке редактора | `seo.json → items[].images.junk_alt`, `a11y.json` | P2 |
| `privacy` | Заявки хранит платформа (зарубежный сервис); для аудитории РФ — вопрос локализации ПДн | `forms.json → items[].check: endpoint-third-party` | по `markets/ru.md` §4.1; находку пишет `privacy`, `forms` передаёт через `for_other_lenses` |
| `security` | Заголовки безопасности сервера владельцу недоступны | `headers.json → home.*` | P3 «платформа» |

## 3. Что исправимо и где

| Задача | Где править | `fix_place` | `owner` |
|---|---|---|---|
| title, description, OG, noindex страницы | настройки SEO страницы | настройки платформы | владелец в CMS |
| `robots.txt` | редактор robots.txt в настройках SEO ([справка](https://support.wix.com/ru/article/editing-your-sites-robotstxt-file)) | настройки платформы | владелец в CMS |
| 301-редиректы | менеджер 301-редиректов ([справка](https://support.wix.com/ru/article/setting-up-a-301-redirect-for-a-page-on-your-site)) | настройки платформы | владелец в CMS |
| Тег заголовка | настройка текстового элемента в редакторе | блок CMS | владелец в CMS |
| Разметка JSON-LD | настройки SEO страницы (раздел разметки) или свой код (на премиум-тарифе — сверить в справке) | настройки платформы | владелец в CMS |
| Свой код в head | настройки сайта → свой код (премиум-тариф — сверить в справке) | шаблон | разработчик |
| Мобильная раскладка | мобильный вид редактора: показать скрытые блоки, проверить порядок | блок CMS | владелец в CMS |
| Плашка платформы и домен | переход на платный тариф и свой домен | внешний сервис | решение владельца |

## 4. Ограничения платформы (P3 «платформа»)

- Сервер, заголовки ответа, сжатие, кэш, набор скриптов движка.
- Каркас адресов задаёт платформа, но префиксы блога и магазина (`post`, `product-page` по умолчанию) меняются в настройках SEO для типа страниц; платформа ставит редиректы со старых адресов ([справка](https://support.wix.com/en/article/customizing-your-pages-url-structure-in-seo-settings), путь в меню сверить в справке). «Неудобный префикс» — P3 с этим путём в `fix`, не ограничение платформы.
- Код страницы недоступен: правки CSS только в пределах редактора и своего кода.

## 5. Ложные срабатывания

- Элементы, скрытые на одной из раскладок, остаются в DOM — не дубль контента и не переполнение.
- Служебные запросы движка, оборванные страховкой Ревизора, — не ошибки сайта.
