# Платформа: Webflow

**Для:** `brief.platform.name = "Webflow"` (`pages.json → stack.cms`).
**Кто читает:** все линзы; больше всего — `seo-tech`, `perf`, `a11y`, `forms`, `privacy`, `legal`.
**Сверено:** 24.10.2026. Хостинг платформы: сервер владельцу недоступен. Пункты с пометкой «сверить в справке» в `fix` пишутся двумя путями.

## 1. Как узнать

- Атрибуты `data-wf-site`, `data-wf-page`; скрипт `webflow.js`; файлы с `website-files.com`; технический домен `*.webflow.io` (`pages.json → beta_signals: preview_domain`).
- Страницы двух видов: статические и шаблоны коллекций CMS (статьи, кейсы, товары): одна разметка на сотни страниц.

## 2. Типовые проблемы по линзам

| Линза | Что проверить | Где в замерах | Важность |
|---|---|---|---|
| `seo-tech` | Технический домен `*.webflow.io` открыт для индекса и дублирует сайт | `seo.json`, если технический домен попал в `pages.json`; иначе — вопрос владельцу (Search Console) | P1 при доказанном дубле; иначе `open_questions` |
| `seo-tech` | Шаблон коллекции: title и description берутся из полей CMS; пустое поле = пустой description на всех страницах коллекции | `seo.json → items[].description.empty`, `site.description_duplicates` | P1 при пустых на шаблоне |
| `seo-tech` | Глобальный canonical не задан или задан с ошибкой (другой домен) | `items[].canonical.host_mismatch` | P1 при чужом хосте |
| `perf` | Анимации платформы (Interactions) прячут блоки до загрузки JS: первый экран пуст без скрипта, LCP позже | кадр fold, `mobile.json → code.motion`, `perf.json` | P1, если первый экран пуст |
| `perf` | Тяжёлые фоновые видео и Lottie в первом экране | `perf.json` (топ-ресурсы) | P2 |
| `a11y` | Кнопки и ссылки собраны из `div` (Div Block с действием) без роли и фокуса; кастомные выпадающие списки и вкладки без клавиатуры | `a11y.json → items[].check`, `axe.json` | P1 на пути к заявке или покупке |
| `privacy` | Заявки из встроенных форм хранит платформа (зарубежный сервис); для аудитории РФ — вопрос локализации ПДн | `forms.json → items[].check: endpoint-third-party` | по `markets/ru.md` §4.1; находку пишет `privacy`, `forms` передаёт через `for_other_lenses` |
| `privacy` | Шрифты Google и Adobe, встройки, счётчики до согласия | `privacy.json → summary.trackers_before_consent`, `cross_border` | по `markets/*` |
| `security` | Заголовки безопасности сервера владельцу недоступны или ограничены | `headers.json → home.*` | P3 «платформа» |
| `i18n` | Встроенная локализация: подпапки языков, hreflang ставит платформа — проверить взаимность и переключатель на ту же страницу | `items[].hreflang` | по `i18n` |

## 3. Что исправимо и где

| Задача | Где править | `fix_place` | `owner` |
|---|---|---|---|
| title, description, OG у статической страницы | настройки страницы (SEO, Open Graph) | настройки платформы | владелец в CMS |
| title, description у коллекции | настройки шаблона коллекции: привязка к полям; заполнить поля у записей | блок CMS | владелец в CMS |
| 301-редиректы | настройки сайта → публикация → 301 redirects | настройки платформы | владелец в CMS |
| `robots.txt`, запрет индексации технического домена, глобальный canonical | настройки сайта → SEO (названия пунктов сверить в справке) | настройки платформы | владелец в CMS |
| JSON-LD, свой код | вставка кода в head страницы или сайта (на платных тарифах сайта — сверить в справке); элемент Embed | шаблон | разработчик |
| Роли и фокус у кастомных элементов | замена Div Block на Button/Link Block, атрибуты в настройках элемента | шаблон | разработчик |
| Анимации первого экрана | отключить начальное «скрыто» у блоков первого экрана в Interactions | шаблон | разработчик |
| Хранение заявок в РФ | внешний обработчик форм или CRM с серверами в РФ (решение владельца) | внешний сервис | решение владельца |

## 4. Ограничения платформы (P3 «платформа»)

- Нет доступа к серверу: заголовки безопасности, сжатие, тонкая настройка кэша — в пределах того, что даёт платформа.
- Свой код в head — на платных тарифах; на бесплатном — только то, что есть в настройках.
- Скрипт платформы и jQuery на каждой странице.

## 5. Ложные срабатывания

- `webflow.js` и jQuery в коде — часть платформы, не «устаревшая библиотека, добавленная разработчиком» (версию всё равно сверить по `headers.json → libraries`).
- Адаптивные картинки с `srcset` платформа строит сама: «нет srcset» здесь не находка, проверять верность `sizes`.
