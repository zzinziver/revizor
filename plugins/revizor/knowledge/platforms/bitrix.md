# Платформа: 1С-Битрикс (Bitrix)

**Для:** `brief.platform.name = "Bitrix"` (`pages.json → stack.cms`).
**Кто читает:** все линзы; больше всего — `seo-tech`, `security`, `perf`, `ecommerce`, `forms`.
**Сверено:** 24.10.2026. Коробочная версия правится полностью (шаблон, компоненты, сервер), поэтому скидки «платформа» нет. Исключение — сайты на конструкторе облачного Битрикс24 (раздел 4).

## 1. Как узнать

- Пути `/bitrix/js/`, `/bitrix/templates/`, `/bitrix/cache/`, `/bitrix/components/`; объект `window.BX`, вызовы `BX.setJSList`; заголовок `X-Powered-CMS: Bitrix Site Manager`; cookie `BITRIX_SM_*`; параметр `bitrix_sessid` в формах.
- Магазин — компоненты каталога и «умный фильтр» (адреса вида `/filter/…/apply/`).

## 2. Типовые проблемы по линзам

| Линза | Что проверить | Где в замерах | Важность |
|---|---|---|---|
| `security` | `/bitrix/admin/` открывается снаружи (форма входа в админку для всех) | `headers.json → probe` (только при `--probe` на своём сайте) | P2; ограничить по IP — решение владельца |
| `security` | Заголовок `X-Powered-CMS` и версия ядра раскрыты | `headers.json → home.disclosure` | P3 |
| `security` | Старые jQuery и библиотеки шаблона | `headers.json → libraries` | по версии |
| `seo-tech` | Дубли `/index.php` и `/`, адреса с заглавными буквами, со слэшем и без | `seo.json → site.url_variants` | P2 |
| `seo-tech` | Служебные параметры в адресах: `?PAGEN_1=`, `?clear_cache=Y`, `?bxajaxid=`, `?sort=`, `?order=`, `?back_url_admin=` — в ссылках и sitemap | `seo.json → items[].links.param_links` (`pagination` — в том числе `PAGEN_N`, `sort`, `filter`, `other`, `samples`); запасной путь — адреса с `?` в `measure/links.json → items[]` (`internal: true`) и в `page.json → links`; sitemap — `site.sitemap.sample`. `items[].links.tracking_params` их **не ловит** (только `utm_`, `yclid`, `gclid`, `fbclid`, `from`): пустое поле — не «чисто» | P2 |
| `seo-tech` | Пагинация `?PAGEN_1=2` с canonical на первую страницу или без canonical | `items[].canonical.*` | P2 |
| `seo-tech` | «Умный фильтр» плодит индексируемые страницы по сочетаниям фильтров | `pages.json → by_template`, sitemap | P1 для магазина |
| `seo-tech` | Карта сайта модуля SEO не перегенерирована: в ней удалённые страницы или нет новых | `site.sitemap` | P2 |
| `facts` | Композитный кэш показывает старые цены и остатки | сравнить цену на карточке, в списке и в разметке | P1 при расхождении цены |
| `perf` | Тяжёлое ядро JS на каждой странице, композит выключен, высокий TTFB | `perf.json` | P2; TTFB > 1,5 с — P1 |
| `privacy`, `legal` | Веб-формы модуля и формы Битрикс24 (CRM): куда уходят данные (`privacy`), согласие отдельной галочкой (`legal`) | `forms.json → items[].check` | по `markets/*`; `forms` передаёт через `for_other_lenses` |
| `stability` | Ошибки PHP в HTML, страница ошибки с путями | `headers.json → error_page.traces` | P1 |
| `copy` | Шаблонные тексты решения из Маркетплейса («Наша компания — лидер…»), «Lorem ipsum» в демо-блоках | `textscan.json` | P0 на виду |

## 3. Что исправимо и где

| Задача | Где править | `fix_place` | `owner` |
|---|---|---|---|
| title, description, H1 | свойства страницы и раздела, SEO-шаблоны инфоблоков | настройки платформы | владелец в CMS |
| canonical, пагинация | компонент списка (настройки canonical), шаблон | шаблон | разработчик |
| Редиректы, слэш, регистр, `/index.php` | `.htaccess` или nginx, модуль редиректов | сервер | разработчик |
| `robots.txt`, Clean-param для служебных параметров | файл в корне или модуль SEO | настройки платформы | владелец в CMS |
| Карта сайта | модуль SEO → перегенерировать, включить автообновление | настройки платформы | владелец в CMS |
| Умный фильтр | шаблон компонента: noindex или canonical для сочетаний, посадочные — только для нужных фильтров | шаблон | разработчик |
| Заголовки безопасности, закрытие `/bitrix/admin/` по IP | конфиг веб-сервера | сервер | разработчик |
| Скорость | композитный режим, кэш компонентов, объединение CSS/JS в настройках главного модуля | настройки платформы | разработчик |

## 4. Конструктор Битрикс24 (облачные сайты)

Если сайт сделан в конструкторе облачного Битрикс24 (служебные адреса и скрипты облака, нет путей `/bitrix/templates/` своего шаблона), правки делаются блоками и настройками страницы. Заголовки сервера, `robots.txt` и редиректы доступны только в тех пределах, что даёт облако: что нельзя — P3 «платформа». Возможности — сверить в справке Битрикс24.

## 5. Ложные срабатывания

- `/bitrix/` в путях к файлам — норма, не раскрытие.
- `bitrix_sessid` в форме — защита от подделки запроса, не утечка.
- Оборванный служебный POST статистики модуля — работа страховки Ревизора.
